GitHub Pages para tu CV estático

GitHub Pages es un servicio gratuito que publica sitios web estáticos directamente desde un repositorio de GitHub. Para un currículum o un portfolio es la opción perfecta: no necesitas servidor, ni pagar hosting, ni mantener nada. Subes tu HTML, CSS y JavaScript, y GitHub se encarga de servirlo con HTTPS, dominio propio y una red de distribución (CDN) rápida en todo el mundo.

Combinado con un diseño estático optimizado a mano, el resultado son páginas que cargan al instante y que puntúan al máximo en SEO y rendimiento, sin el peso de un framework.

¿Por qué estático en GitHub Pages?

  • Gratis y sin servidor: nada de VPS, Docker ni mantenimiento. Cero coste.
  • Sin autohosting: no dependes de tu luz ni de tu conexión; lo sirve la infraestructura de GitHub.
  • HTTPS y dominio propio: certificado automático y soporte para tu dominio personalizado mediante un fichero CNAME.
  • Despliegue con git push: cada cambio que subes se publica solo.
  • Rendimiento inmejorable: al ser archivos estáticos servidos por una CDN, la carga es casi instantánea.

Cómo publicarlo paso a paso

El proceso es muy sencillo. Para un sitio de usuario, el repositorio debe llamarse tu-usuario.github.io:

  1. Crea un repositorio público con el nombre tu-usuario.github.io.
  2. Sube tu web estática (al menos un index.html) a la rama main.
  3. En Settings → Pages, elige la rama main como origen.
  4. En un par de minutos tu web estará en https://tu-usuario.github.io.
  5. ¿Dominio propio? Añade un fichero CNAME con tu dominio y crea el registro DNS correspondiente.
Ejemplo: subir tu web y publicarla 
# Clona tu repo y entra en él
git clone https://github.com/tu-usuario/tu-usuario.github.io.git
cd tu-usuario.github.io

# Añade tu web estática (index.html, css/, js/, images/)
# Para un dominio propio (opcional):
echo "www.tudominio.com" > CNAME

git add .
git commit -m "Mi CV web estático"
git push origin main
# Listo: GitHub Pages lo publica automáticamente

Dominio propio y HTTPS

Si quieres que tu CV se vea en www.tudominio.com en lugar de usuario.github.io, solo tienes que apuntar tu dominio a GitHub Pages:

DNS para dominio personalizado (ejemplo) 
# Un subdominio (www) con un registro CNAME:
www    CNAME    tu-usuario.github.io

# O el dominio raíz con registros A a las IPs de GitHub Pages:
@      A        185.199.108.153
@      A        185.199.109.153
@      A        185.199.110.153
@      A        185.199.111.153

Después, en Settings → Pages, escribe tu dominio en Custom domain y activa Enforce HTTPS. GitHub emite el certificado automáticamente.
